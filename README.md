## About

I'm an engineering student at **Vishwakarma Institute of Technology (VIT Pune)**, specializing in **Artificial Intelligence, Machine Learning, and Systems Engineering**.

My technical focus centers on practical machine learning pipelines, algorithmic problem-solving, and telemetry architectures. I have competed and led builds in fast-paced hackathons, including **Mumbai Hacks 2025** (Finalist with *FinBuddy*, an ensemble voice-first financial guidance platform powered by 11 ML models) and **iSIH 2026** (*OFFAIR*, a resilient offline emergency communications protocol).

Proficient in **Python** for machine learning, model validation, and predictive analytics, and **C++** for core data structures, algorithms, and systems performance.

📍 Pune, Maharashtra &nbsp;·&nbsp; 🎓 VIT Pune, B.Tech &nbsp;·&nbsp; 🎯 Open to AI / ML & Software Engineering opportunities
